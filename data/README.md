# Dataset

`spam.csv` is a commonly distributed CSV version of the [SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection) created by Tiago A. Almeida, José María Gómez Hidalgo, and Akebo Yamakami.

- Source: UCI Machine Learning Repository
- License: CC BY 4.0
- Included records: 5,572
- Modeled fields: `v1` (label) and `v2` (message)

The remaining empty columns in this distribution are ignored by the training script.
